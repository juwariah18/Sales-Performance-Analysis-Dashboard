# Sales-Performance-Analysis-Dashboard
Sales Analysis Dashboard is an Excel-based data analysis project created using the Global Superstore 2016 dataset. The dashboard uses Pivot Tables and charts to analyze overall sales performance and present key business insights in a clear visual format.  

## Analysis
- Total Revenue
- Sales by Category
- Yearly Sales Trends
- Department-wise Revenue (Category)

## Tools
- Excel
- Pivot Tables
- Data Visualization

## Dataset
Global Superstore 2016
